## D2. Hooks and required rituals

### Pre-commit scope gate

- The pre-commit hook gets staged added/copied/modified/renamed/deleted paths, exits early when nothing is staged, and otherwise fails closed if `.dispatch-scope` is absent (`.githooks/pre-commit:2`, `.githooks/pre-commit:3`, `.githooks/pre-commit:7`, `.githooks/pre-commit:8`). Each non-comment scope line is CR-stripped and whitespace-trimmed before matching (`.githooks/pre-commit:12`, `.githooks/pre-commit:39`).
- Matching is shell `case` glob matching, `case "$f" in $pat)`, not prefix matching (`.githooks/pre-commit:42`). Consequently a literal scope line `docs/` does not match a staged child such as `docs/v2/about/index.html`, while `docs/*` does; the current working-tree `.dispatch-scope` contains `docs/*` (`.dispatch-scope:1`). This is the exact case-glob semantic behind the observed `docs/` fail / `docs/*` work distinction (`.githooks/pre-commit:39`, `.githooks/pre-commit:42`).
- `.dispatch-scope` is a staging allowlist, not authorization to edit: every staged path except the scope file itself must match a non-comment pattern or commit is rejected (`.githooks/pre-commit:30`, `.githooks/pre-commit:31`, `.githooks/pre-commit:44`). Dispatch writers must provide exact staging paths and Codex must stage named paths, never `git add .` or `git add -A` (`AGENTS.md:60`, `AGENTS.md:107`).
- Protected paths are `src/v2/core/*`, `.githooks/*`, `AGENTS.md`, and `CLAUDE.md`; they require both a Hudson dispatch and the per-command `ASTER_PROTECTED_OK` override (`.githooks/pre-commit:32`, `.githooks/pre-commit:34`, `AGENTS.md:111`). `INVARIANTS.md` and `src/v2/*_FOUNDING.md` are mechanically additive/annotation-only: the proof used by the hook is `git diff --cached -- "$doc" | grep -c '^-[^-]'`, and any counted deletion is rejected without the protected override (`.githooks/pre-commit:50`, `.githooks/pre-commit:53`, `.githooks/pre-commit:55`).
