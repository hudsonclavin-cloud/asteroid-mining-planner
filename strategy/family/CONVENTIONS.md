# Aster family — shared conventions (v0, PROPOSAL)

**Status:** PROPOSAL, leads-grade. Written 2026-10-26 from a read-only review of the five repos; corrected the same day after the adversarial verification pass (see adoption record). Nothing here locks a DEC, amends an invariant, or changes any member repo. A member adopts a convention by adding a dated line to its own rules file; until then this document describes practice, not policy.

**Why this document exists.** Four of the five repos already share most of one working culture, arrived at separately. Writing it down once lets a new repo (or a new agent session) inherit it in a page, and makes the places where the repos *disagree* visible so they can be reconciled deliberately instead of by accident. The aim is a shared vocabulary, not a monorepo: each repo keeps its own ids, history, hooks and deploy.

## Where the repos disagree (reconcile deliberately)

1. **Push policy (C7).** Aster forbids agent pushes and enforces it with a hook; PartForge documents push-on-every-commit. Both are Hudson's own rules. Pick one per repo and write it in that repo's rules file; the family should not silently assume Aster's.
2. **Label vocabulary (C1).** PartForge's `cited / user / tool default` answers "who stands behind this number", which the three-label scale does not. Proposal: keep both axes everywhere they apply, and spell the three-label scale with the same casing (`[Certain]`) so grep works across repos.
3. **Identifier schemes.** Aster: `INV-nnn`, `DEC-s-n`, `OQ-s-n`, slices. Skyhook: `DECISION_LOG` items, `VM-/LR-/MP-/ST-/RB-/TS-` artifact ids, Rev A/B/C. PartForge: `Gen N`. Idea-Bank: idea numbers 01–75. Do **not** unify these; they encode each repo's history. A family index can cross-reference them.
4. **Licensing.** Aster is MIT (but its LICENSE file wraps the text in prose, so GitHub reports it as NOASSERTION), PartForge is Apache-2.0, Idea-Bank is public with **no LICENSE file**, and Skyhook and the suborbital stub are **private** with no LICENSE (GitHub API, read 2026-10-26). An unlicensed public repo is all-rights-reserved by default, which contradicts the open, inspectable posture the READMEs take; Skyhook needs a LICENSE *before* it is ever flipped public. Decide per repo (MIT or Apache-2.0 both fit; read PartForge's `headless/README.md` GPL note on openscad-wasm first). This is the one step on this page that is not free to undo: an open-source grant cannot be revoked for copies already distributed.
5. **CI.** Aster and Skyhook run CI on push; PartForge and Idea-Bank have local gates only (`node tests/run.mjs`, `node tools/check.mjs`). Adding a one-job workflow that runs the existing local gate is cheap and turns "tests exist" into "tests run on every push".

## What the family should NOT centralize

- Code. No shared library until two repos need the same function for a shipped feature; the K2 prototype's snapshot-with-hash pattern (copy `rev_a.json`, record its sha256 and source commit) is the right cross-repo dependency mechanism today.
- Decision ids, slice numbering, or history.
- Deploys. Each repo keeps its own Pages site; the family page only links.
- Hooks. Aster's `.githooks` fit Aster's threat model (a Codex session once deleted 5,165 lines of founding docs). Other repos adopt a hook only if they have the same exposure.
